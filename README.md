# splatstudio.app - 100% WORKING

## Деплой для владельца (без кода)

### Вариант 1: Vercel (рекомендуется)
1. Зайди на vercel.com/new
2. Выбери cargounetcom/splatstudio-1, ветка feat/shark-install
3. Нажми Deploy
4. Settings -> Domains -> Add splatstudio.app -> скопируй DNS

### Вариант 2: GitHub Pages
1. GitHub -> Settings -> Pages -> Source: gh-pages, Domain: splatstudio.app
2. В Cloudflare/домене добавь CNAME: @ -> cargounetcom.github.io

Сайт будет жить на https://splatstudio.app
